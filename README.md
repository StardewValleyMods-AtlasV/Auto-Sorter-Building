# Auto-Sorter Building

Manually sorting your items always takes so much time, add in a bunch of mods that add new items and it takes even longer!

This mod can help! It adds a new building that can be built by Robin that
automatically sorts all your items by catagory into the chests on the inside
that you place!




To use it, this is all you need to do :

    Buy the building from Robin and wait for it to be constructed.
    Place a sign that can have an item displayed on it anywhere in the building.
    Place any kind of chest directly below the sign.
    Place an item on the sign with a catagory that matches the items you want to be stored in the chest.
    Then head on outside and place your items in the box to the right of the door.
    When you close the box your items will be sorted automatically!

The building can support any number of chests with signs inside!


There are also some fall back features so that if it doesn't find a chest that matches, your items will still be safe!

    If the building finds 2 chests with catagories that match but one doesn't
    have enough space, It will place the remaining items in the other chest.
    if the building finds a chest with a catagory match but doesn't have
    enough space, or there isn't a chest for that catagory, it will place the items in chest below an empty sign.
    If the building can't do either of these the items will be placed back into the box you placed your items in.
